# Agent Lab Hermes

> AI Agent 運用ナレッジベース — ワークフロー設計と再利用可能なスキルテンプレート。

[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

## 概要

本リポジトリは、AI Agent を本番環境で運用するための実践パターンをまとめたものです。
ワークフローの構成、永続メモリの管理、バージョン管理されたナレッジベースの維持、
再利用可能な運用スキルの構築方法を解説します。

Hermes Agent インスタンスの運用経験を汎用化し、他の Agent 運用者が
自身のシステムに適応できるようにしています。

## アーキテクチャ

Agent 運用は4層設計に従います：

```
ワークフロー  →  スキル  →  ドキュメント  →  設定
   (設計)        (実行)       (説明)         (値)
```

| 層 | 内容 | 対象 | 変更頻度 |
|----|------|------|----------|
| **ワークフロー** | アーキテクチャ設計 — システムが何をし、なぜそうするか | アーキテクト、Agent | ほぼなし |
| **スキル** | 手順書 — 具体的なタスクの実行方法 | Agent、運用者 | たまに |
| **ドキュメント** | 設計説明 — なぜこの設計なのか | 人間、新しい Agent | スキル変更時 |
| **設定** | インスタンス設定 — 具体的な値とパラメータ | Agent、デプロイスクリプト | 頻繁 |

各ワークフローとスキルは自己完結型のユニットで、独自のドキュメント、
リファレンス、テンプレートを含みます。
